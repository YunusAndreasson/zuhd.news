United States — Sepolia's gas limit jumps from about 60 million to 200 million.

Larger blocks fit more transactions but demand more from the computers that run Ethereum.

Prysm's validator software got version 7.2.1 late Monday, because the previous release would have left validators producing smaller blocks.

The Glamsterdam test on Sepolia runs Tuesday, before developers set capacity for Ethereum's main network.
