Washington — One tool draws a digital fence around any address.

A leaked document lists tools used by Immigration and Customs Enforcement (ICE), including Locate X, which searches phone-location data harvested through ordinary apps, plus facial recognition and undercover browsing systems.

Homeland Security confirmed the agency uses such technology but did not detail current access to each tool.
