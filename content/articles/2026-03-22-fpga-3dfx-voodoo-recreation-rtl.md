San Francisco — Dead silicon can now be rebuilt from code. A developer rebuilt the 1996 3dfx Voodoo graphics chip in SpinalHDL on a field-programmable gate array (FPGA), replicating what once required a full engineering team. The code is on GitHub as a template for reviving other extinct 1990s chips before their last originals fail.
