San Francisco — Anthropic's agents formalized Fermat's proof in 11 days.

The agents translated, not discovered, Wiles's already-proven result.

Formalization turns a proof into code a machine checks line by line, work mathematicians call drudgery.

Kevin Buzzard's five-year, human-led formalization project is now obsolete.
