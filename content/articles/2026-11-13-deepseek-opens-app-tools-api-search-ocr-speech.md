China — Developers can now rebuild DeepSeek's app one-for-one.

Developers pay tool-call fees on top of token costs.

Developers switch on a parameter and DeepSeek's servers run search, link reading, file parsing, text recognition and speech, stitching context automatically.

DeepSeek warns developers serving outside users must run safety checks and meet content-review, model-registration and AI-labelling duties.

Only DeepSeek-V4.1-Flash supports the new features so far.
