San Francisco — Fable flags routine code reviews as cybersecurity threats.

Anthropic's public Mythos model pauses any prompt it labels cybersecurity-related — including standard code review requests, researchers say.

Anthropic has a Cyber Verification Program offering broader access, but no timeline for easing the restrictions has been given.
