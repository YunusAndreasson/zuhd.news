A malicious script compromised Wikipedia's administrator accounts. A Wikimedia Foundation employee testing API limits accidentally imported the script; admin access grants the ability to delete articles and modify Wikipedia's global settings. Engineers audited accounts Thursday while Wikipedia remained in read-only mode, blocking all editing globally.
