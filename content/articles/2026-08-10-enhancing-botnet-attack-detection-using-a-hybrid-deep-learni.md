London — A new model hit 99.1% accuracy detecting botnets.

Fewer false negatives catch botnets before they launch attacks or leak data.

The model fuses network-flow and Domain Name System query patterns, then explains each call using two interpretability techniques.

Researchers haven't tested it against botnets built specifically to evade detection.
