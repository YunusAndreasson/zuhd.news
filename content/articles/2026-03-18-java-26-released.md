Java 26 ships with HTTP/3 and ahead-of-time caching. The release sets the stage for Project Valhalla — value types that eliminate heap overhead — expected in a later 2026 release. Valhalla would alter how every JVM application allocates memory, affecting a platform running on 3 billion devices.
