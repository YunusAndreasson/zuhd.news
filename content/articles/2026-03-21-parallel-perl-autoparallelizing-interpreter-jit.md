Old Perl code now runs on multiple cores. Presented at German Perl Workshop 2026, the tool uses JIT compilation to autoparallelize single-threaded programs without modifying them. Jelinek, the tool's creator, presented to engineers maintaining Perl-heavy infrastructure but has not released source code.
