Washington — The [US](country:US) Federal Communications Commission would require government ID from every phone subscriber.

The proposal requires name, address, and government ID from all subscribers, which domestic-violence groups say strips the anonymity survivors need for safety.

Initial comments close June 25; the FCC has set no implementation timeline.
