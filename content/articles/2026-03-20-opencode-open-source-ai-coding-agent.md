OpenCode launched a cross-platform desktop app this week. The open-source project has 120,000 GitHub stars, connects to 75 AI providers, and does not store users' code. The desktop beta on macOS, Windows, and Linux brings OpenCode to developers who do not use the terminal — a larger audience than any command-line tool can reach.
