Boston — Two genetic codes ran inside one system at once.

An organism using an alien code could resist viruses and share no genes with the wild.

Researchers built matched ribosomes and transfer RNAs so each code ignores the other's machinery entirely.

The team tested this outside living cells; it has not yet been tried inside one.
