Shanghai — ChangXin Memory Technologies (CXMT) shares rose 530% on debut.

[China](country:CN)'s top memory chipmaker holds 8% of the dynamic random-access memory market, analysts say, as rivals divert supply to pricier AI chips, driving a global shortage.

Apple, Microsoft and Dell have already raised prices; new CXMT capacity takes about a year to arrive.
