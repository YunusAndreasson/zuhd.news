Mistral's Leanstral proves the code it generates is correct. Leanstral uses Lean 4, a proof assistant, to guarantee code against formal mathematical specifications rather than relying on test coverage alone. Mistral released the model weights and FLTEval, a new formal proof benchmark, under Apache 2.0 — setting a standard other AI coding tools will now be measured against.
