London — A new chatbot turns questions into SQL without any large language model.

A closed, fixed database vocabulary needs no frontier model to search it correctly.

A grammar-constrained parser can only emit valid queries, while a language model can emit fluent but wrong ones.

Researchers report 90% accuracy, and local deployment could keep data off US servers.
