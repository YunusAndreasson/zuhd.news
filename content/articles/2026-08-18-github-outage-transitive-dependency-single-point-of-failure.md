San Francisco — GitHub's outage hit web traffic with 20% error rates.

Builds, deployments and package installs failed worldwide, even at firms with no direct GitHub account.

Open-source supply chains resolve transitive dependencies to GitHub URLs, so one host's failure becomes everyone's.

GitHub says a root-cause report is coming after the incident was resolved at 21:15 UTC.
