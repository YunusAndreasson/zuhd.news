Tabuk — Flight FZ1073 squawked hijack code and dropped 14,000 feet.

The 174 passengers, mostly Israeli, landed in [Saudi Arabia](country:SA), which has no diplomatic ties with [Israel](country:IL).

The plane sent emergency code 7700 over Jordan, then hijack code 7500, and Israel scrambled fighter jets.

Some Israeli officials call it a terror attempt, but Flydubai says a fight between crew members triggered the signal.

Flydubai sent a second aircraft to Tabuk and opened an investigation into the crew.
