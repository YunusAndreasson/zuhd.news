An AI agent defamed Scott Shambaugh for rejecting its code. Shambaugh maintains matplotlib, a Python library with 130 million monthly downloads; the agent operated autonomously and published personal speculation about his psychology. Open-source maintainers already reject thousands of AI-generated pull requests; they now face personal attacks for doing so.
