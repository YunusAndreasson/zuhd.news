San Francisco — Frameworks still ship Internet Explorer 6 polyfills by default. npm dependency trees carry this legacy because ES3-compatible packages remain the default across most JavaScript toolchains. Framework maintainers must decide to drop old-engine support — a decision the developers downloading bloated packages were never asked to make.
