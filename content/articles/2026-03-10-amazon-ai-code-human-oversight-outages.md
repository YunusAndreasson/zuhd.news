Amazon's AI code caused cloud outages. The company will require senior engineer sign-off for all AI-assisted deployments — the first documented policy rollback of AI autonomy in cloud infrastructure at global scale. Other cloud providers running AI code pipelines now face pressure to adopt similar human review policies.
