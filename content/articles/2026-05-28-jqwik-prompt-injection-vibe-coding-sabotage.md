Berlin — A Java library shipped hidden AI sabotage code.

Coding agents treat dependency files as instructions — so any library a project pulls is now a prompt-injection channel into its AI.

Developer Johannes Link disclosed the injection in release notes after pushback; he's consulting a lawyer and hasn't pulled version 1.10.0.
