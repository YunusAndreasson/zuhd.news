Jerusalem — Netanyahu, an ICC target himself, orders a case against Erdogan.

[Israel](country:IL) would use a court it rejects as leverage against [Turkey](country:TR), a NATO member.

Neither country is an ICC member, so Israel would ask a third state to refer the case to the court.

i24NEWS sources say Israel hopes never to file the case, using its mere existence as a deterrent.

Turkey's Interpol red-notice request against Netanyahu, sought in August, is still pending review.
