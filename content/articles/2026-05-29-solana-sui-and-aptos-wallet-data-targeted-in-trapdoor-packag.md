San Francisco — Crypto attackers weaponized AI config files to exfiltrate secrets.

Security firm Socket found 34 packages across 3 package registries planting hidden instructions in AI config files to hijack coding assistants.

The attacker submitted pull requests to open-source repos, disguising malicious config files as legitimate contributions.
