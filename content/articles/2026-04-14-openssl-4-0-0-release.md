London — OpenSSL 4.0.0, the first major version bump since 2021, is released. Every prior major release forced migrations across the internet's dependency tree; this one begins the same process for every server, container, and package manager. Linux distributions and runtimes must set migration timelines; 3.x long-term support is unconfirmed.
