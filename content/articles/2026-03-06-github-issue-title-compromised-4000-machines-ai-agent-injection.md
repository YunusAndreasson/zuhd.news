A GitHub issue title compromised 4,000 developer machines. An attacker hid an npm install command inside a GitHub issue title; Cline's AI triage bot ran it automatically, stealing developer credentials. Security researcher Adnan Khan warns every team running AI triage bots on public repositories faces the same exposure.
