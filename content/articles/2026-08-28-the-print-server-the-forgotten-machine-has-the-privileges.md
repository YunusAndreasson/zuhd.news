Melbourne — Hackers are actively exploiting a print-server flaw.

Print-quota software sits inside networks at universities, hospitals and government offices worldwide.

Print servers run with high privileges and sit deep inside networks, so they are rarely part of any patch cycle.

PaperCut has not yet published which versions are patched or how attackers are getting in.
