Cairo — [Egypt](country:EG) postponed its criminal procedures code a year, hours before enactment.

The code governs arrest, remand detention and trial for every criminal defendant in the country.

The government says the delay lets it finish a digital system for court notifications and remote hearings.

The code shortens remand, but does not stop stacked charges from chaining consecutive remand periods.

Current detention rules stay in force until the code takes effect in October 2027.
