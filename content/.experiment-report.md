# Pipeline Experiment Report — 2026-03-25

## Executive Summary

An overnight experiment session (00:00–08:00 UTC) ran the editorial pipeline manually with parameter adjustments between cycles. The session discovered the **root cause of the multi-source drought**: the NewsAPI.ai key was missing from the systemd environment, so every cycle for the past day+ ran on RSS feeds only (0 API events).

### Key Findings

1. **Root cause fix (highest impact):** NewsAPI.ai key was never loaded in systemd. Fixed by sourcing `.env` in `run-cycle.sh`. First cycle with API active produced 50 events and 8 multi-source stories — versus 0 previously.

2. **S3 "must now" pattern eliminated:** Adding an explicit anti-pattern to the writer prompt ("Never end with 'X must now Y'") reduced prescriptive endings from ~20% to 0% across 12+ articles.

3. **S2/S3 redundancy reduced:** Adding "each sentence must introduce new information" to the writer prompt reduced the restatement pattern.

4. **Category misclassification fixed:** `crypto/bitcoin/fintech` moved from tech → economy in the keyword classifier.

5. **Feed freshness improved:** Article queries now look back 1 day (`dateStart = yesterday`), catching late-indexed content during early-UTC cycles.

## Remaining Issues

1. **Multi-source politics rate still untested at scale** — API timed out in 2/3 cycles. Need a full day with working API to measure.

2. **Category misclassification** — `environment` → `science` catches some policy stories. Edge case (Rio Tinto/Apache land). Selector should override, not the classifier.

3. **TASS over-representation** — 11x in yesterday's articles. With API working, TASS becomes one source among many in multi-source panels rather than the only available source.

4. **Washington dateline overload** (37.5%) — structural issue. US-based sources dominate the API. Need to monitor whether `GAP_COUNTRIES` + non-Western curated sources reduce this with API active.

5. **Tech articles weakest editorially** — product announcements instead of structural analysis. This is a selection problem, not a writing problem. The selector prompt's "Protect unique stories" guidance should steer away from generic product coverage.

6. **Systemd service still needs the key** — `.env` sourcing works from the script, but the environment variable should also be set directly in the systemd service for belt-and-suspenders reliability.
