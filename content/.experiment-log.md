# Pipeline Experiment Log — 2026-03-25

## Mission
Optimize the editorial pipeline for multi-source politics articles, article quality, and the zuhd reader persona: intelligent Muslims in tech who care about the ummah.

## Baseline (from audit of 40 articles, 2026-03-24)
- 55% single-source overall (politics: 50%, tech: 67%, economy: 43%, science: 60%)
- Only 20% true cross-country multi-source
- 82% concrete hooks, 70% mechanism in S2, 75% tension in S3
- S3 defaults to "must now" prescriptions in ~20% of articles
- S2/S3 redundancy (restating same point) in ~10%
- 37.5% US-datelined — too heavy for global site
- Tech articles weakest editorially (product announcements, not structural analysis)
- **ROOT CAUSE: NewsAPI.ai key was missing from systemd environment — 0 API events all day. Entire pipeline ran on RSS-only.**

## Cycle 1 — 00:01 UTC

**Result:** 6 articles (feed depleted — 9th cycle on same day's data)
**Multi-source politics:** 1/3 (33%) — visa bonds piece (Fox News + Al Jazeera)
**Quality issues:**
- Azerbaijan ICD: S2/S3 redundancy ("South Caucasus" repeated)
- GitHub: S3 restates S2's single-vendor point
**Conclusion:** Feed exhausted, can't evaluate fetch params yet.

## Between cycles: root cause fix
1. **NEWSAPI_KEY missing from systemd** — added .env loading to run-cycle.sh
2. **Writer prompt:** added "must now" anti-pattern + S2/S3 no-repeat rule
3. **Editor prompt:** added "must now" to tension test watchlist
4. **Category fix:** moved crypto/bitcoin/fintech from tech → economy in zuhdCategory()
