# UI and UX polish — 20 September 2026

Validated with Argent on the Android 15 `zuhd-qa` emulator (411 × 914 dp), Expo development build, Metro port 8082.

## Changes

- Restricted globe gesture ownership to the exposed map, keeping header buttons and story controls from also triggering map taps or cancelling camera movement. Adjusted tap and pinch coordinates for the inset surface.
- Re-measure story cards after reading font/size changes and updates to existing story text or thread context. Appearance changes and minute ticks retain the measurement.
- Restored Search's introductory and no-results guidance: empty states now retain their natural height in content-sized native sheets.
- Enlarged country carousel controls from 12 dp to separate 48 dp targets. Retain page alignment after width changes, clamp paging indices, and reset for another country.
- Respect Reduce Motion for programmatic country-card paging.
- Corrected ranking offsets for the variable-height description/source header. Wait for content and native layout before positioning once; preserve subsequent manual scrolling.
- Guarded asynchronous audio foreground/resume work against dismissal, date changes, and unmount.
- Cancel delayed zoom and notification-primer work when the home screen unmounts.
- Reused fixed Skia texture-size objects so unchanged beacon/overlay textures do not rebake because of object identity changes.
- Made the deprecated-API test report child-process launch errors directly instead of misleadingly reporting missing findings.

## Verification

`npm run verify`: 61 suites, 562 tests passed; TypeScript, Biome, and deprecated-API checks passed. Rechecked TypeScript and Biome after the final ranking scheduling adjustment. Added regression tests for gesture bounds/coordinate translation and asynchronous audio disposal.

Emulator checks passed: menu with story open and closed; sources; search results, empty search, no matches, and clear; save/reopen/remove; light/dark appearance and default/large text; three country cards; country ranking initial positioning and manual scrolling; globe pan, pinch, and tap-to-collapse; next story; briefing load/play/pause/hide.

Recorded flows in `.argent/flows` both passed uninterrupted replay: settings and country ranking. Ranking uses Iran's bundled GDP value as the visible-row assertion; update that fixture if the bundled country dataset changes.

## Performance evidence and limits

Hermes/React profiles of light → default size → large size → dark:

| Operation | Before main commit | After main commit |
| --- | ---: | ---: |
| Light appearance | 421 ms | 364 ms |
| Default size | 370 ms | 689 ms |
| Large size | 312 ms | 724 ms |
| Dark appearance | 333 ms | 327 ms |

These are single development-build emulator captures, not release benchmarks or a statistically controlled comparison. The reading-size correction deliberately adds previously missing card measurement work; it fixes stale layouts at a measurable cost. No overall speedup is claimed. CPU inspection attributed much of MiniGlobe render self-time to development JSX `createTask` overhead. Stable texture sizes remove a specific unnecessary effect dependency; appearance-triggered projection still offers a future optimization opportunity.

Raw captures remain under `/tmp/argent-profiler-cwd`; the latest report is `react-profiler-report.md`. Android native profiling and iOS verification were not performed.
